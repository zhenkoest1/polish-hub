## Вопросы: Kogo? Co?

Biernik — падеж прямого дополнения. Используется после глаголов действия, когда действие направлено на объект.

---

## Когда используется

После глаголов действия:

| Глагол | Перевод | Пример |
|--------|---------|--------|
| *mieć* | иметь | *Mam nowy telefon.* |
| *widzieć* | видеть | *Widzę piękną dziewczynę.* |
| *czuć* | чувствовать | *Czuję radość.* |
| *pisać* | писать | *Piszę list.* |
| *czytać* | читать | *Czytam książkę.* |
| *kupić* | купить | *Kupię nową aplikację.* |
| *robić* | делать | *Robię projekt.* |
| *sprawdzać* | проверять | *Sprawdzam raport.* |
| *planować* | планировать | *Planuję podróż.* |
| *znać* | знать | *Znam tego człowieka.* |
| *lubić* | любить/нравиться | *Lubię polską kuchnię.* |
| *kochać* | любить | *Kocham tę dziewczynę.* |

---

## Окончания существительных

| Род | Правило | Mianownik → Biernik |
|-----|---------|----------------------|
| Мужской неодушевлённый | = Mianownik (без изменений) | *telefon → telefon* |
| Мужской одушевлённый | = Dopełniacz (-a) | *wróg → wroga, szef → szefa* |
| Женский (-a → -ę) | меняем -a на -ę | *firma → firmę, książka → książkę, aplikacja → aplikację* |
| Средний | = Mianownik (без изменений) | *zmęczenie → zmęczenie, prawo → prawo* |

> **Ключевое правило:** Мужской одушевлённый в Bierniku выглядит как Dopełniacz. Это главное отличие от неодушевлённых!

---

## Окончания прилагательных

| Род | Правило | Mianownik → Biernik |
|-----|---------|----------------------|
| Муж. неодушевлённый | = Mianownik | *nowy kurs → nowy kurs* |
| Муж. одушевлённый | -y/-i → -ego, сущ. + -a | *surowy szef → surowego szefa* |
| Женский | -a → -ą, сущ. -a → -ę | *nowa aplikacja → nową aplikację* |
| Средний | = Mianownik | *proste rozwiązanie → proste rozwiązanie* |

### Примеры по родам

- Муж. неодуш.: *Widzę nowy komputer.* (= Mianownik)
- Муж. одуш.: *Widzę nowego pracownika.* (= Dopełniacz)
- Женский: *Widzę piękną dziewczynę.*
- Средний: *Widzę stare krzesło.* (= Mianownik)

---

## КРИТИЧЕСКОЕ ПРАВИЛО: NIE + Biernik → Dopełniacz

При отрицании глагола Biernik заменяется на Dopełniacz!

| Утверждение (Biernik) | Отрицание (Dopełniacz) |
|------------------------|------------------------|
| *Mam sukces.* | *Nie mam sukcesu.* |
| *Widzę problem.* | *Nie widzę problemu.* |
| *Czuję radość.* | *Nie czuję radości.* |
| *Mam czas.* | *Nie mam czasu.* |
| *Znam odpowiedź.* | *Nie znam odpowiedzi.* |
| *Lubię tę książkę.* | *Nie lubię tej książki.* |

> **Это одно из самых важных правил польской грамматики.** В русском такого нет — мы говорим «не вижу проблему» (Вин.п.), но в польском это обязательно Dopełniacz.

---

## Примеры в контексте

1. *Planuję długą podróż do Krakowa.* — Планирую долгое путешествие в Краков.
2. *Znam tego profesora — jest bardzo surowy.* — Знаю этого профессора — он очень строгий.
3. *Kupuję nową książkę i czarną kawę.* — Покупаю новую книгу и чёрный кофе.
4. *Nie mam dobrego pomysłu.* — У меня нет хорошей идеи. (отрицание → Dopełniacz)
5. *Lubię polskie filmy, ale nie lubię polskiej pogody.* — Люблю польские фильмы, но не люблю польскую погоду.
6. *Sprawdzam każdy raport przed wysłaniem.* — Проверяю каждый отчёт перед отправкой.

---

## Частые ошибки

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| *Widzę szef.* | *Widzę szefa.* | Одушевлённый муж. род — окончание как в Dopełniaczu |
| *Nie mam czas.* | *Nie mam czasu.* | После отрицания Biernik → Dopełniacz |
| *Znam ta kobieta.* | *Znam tę kobietę.* | Женский род: -a → -ę, ta → tę |
| *Kupuję nowego telefon.* | *Kupuję nowy telefon.* | Телефон неодушевлённый — Biernik = Mianownik |

> **Подсказка для русскоговорящих:** Польский Biernik очень похож на русский Винительный, но правило с отрицанием (NIE → Dopełniacz) срабатывает ВСЕГДА, без исключений.
