## Вопросы: Kogo? Czego?

Dopełniacz — падеж отсутствия, принадлежности и количества. Отвечает на «кого? чего?» (= русский Родительный).

---

## Когда используется

| Ситуация | Формула | Пример |
|----------|---------|--------|
| **Отрицание** (nie ma / nie mam) | nie ma + D | *Nie ma kryzysu.* — Нет кризиса. |
| **bez** (без) | bez + D | *Bez wolności nie ma demokracji.* |
| **z / od / do** (из / от / до) | z/od/do + D | *Od początku do końca.* |
| **dla** (для) | dla + D | *Dla każdego imperium.* |
| **podczas** (во время) | podczas + D | *Podczas pandemii.* |
| **brak** (отсутствие) | brak + D | *Brak zaufania do instytucji.* |
| **ile / dużo / mało** (сколько) | ile/dużo/mało + D | *Dużo pieniędzy.* |
| **Принадлежность** (чей? чего?) | rzecz + D | *Upadek imperium. Wartość waluty.* |
| **После отрицания** (nie + Biernik → D) | nie widzę + D | *Nie widzę wzorca.* |

> **Подсказка для русскоговорящих:** Польский Dopełniacz почти идентичен русскому Родительному. Те же предлоги (без, от, до, для, во время), та же функция отрицания и принадлежности. Это ваш самый «родной» падеж!

## Окончания существительных — единственное число

### Мужской род

| Тип | Окончание | Примеры |
|-----|-----------|---------|
| Одушевлённые (люди, животные) | **-a** | *lider → lidera, miliarder → miliardera, ekonomista → ekonomisty* |
| Абстрактные и неодушевлённые | **-u** (большинство) | *kryzys → kryzysu, fakt → faktu, dług → długu, upadek → upadku, porządek → porządku, etap → etapu, fundusz → funduszu* |
| Исключения (абстрактные на **-a**) | **-a** | *wzorzec → wzorca* |

> **Правило:** Большинство мужских существительных берут **-u**. Одушевлённые (люди, животные) берут **-a**. Некоторые абстрактные тоже берут **-a** (их нужно запомнить).

### Женский род

| Тип | Окончание | Примеры |
|-----|-----------|---------|
| После твёрдой согласной | **-y** | *władza → władzy, waluta → waluty, reforma → reformy, cisza → ciszy* |
| После **k, g** | **-i** | *gospodarka → gospodarki* |
| На **-ja** | **-ji** | *narracja → narracji, rewolucja → rewolucji* |
| На **-ść** | **-ści** | *wolność → wolności, korzyść → korzyści* |

> **Правило:** Женские на **-a**: после твёрдой → **-y**, после мягкой / k / g → **-i**. Женские на **-ść** → **-ści**. Женские на **-ja** → **-ji**.

### Средний род

| Тип | Окончание | Примеры |
|-----|-----------|---------|
| На **-o** | **-a** | *bogactwo → bogactwa, źródło → źródła* |
| На **-e** | **-a** | *wydarzenie → wydarzenia, zaufanie → zaufania, narzędzie → narzędzia, badanie → badania* |
| На **-um** | **-um** (без изменений!) | *imperium → imperium* |

> **Правило:** Средний род: **-o → -a**, **-e → -a**, **-um → -um** (не меняется!).

## Окончания существительных — множественное число

| Род | Окончание | Примеры |
|-----|-----------|---------|
| Мужской | **-ów** (большинство) | *faktów, wzorców, imperiów, długów, kryzysów* |
| Женский твёрдый | **нулевое** | *reform, walut* |
| Женский мягкий | **-i** | *narracji, rewolucji* |
| Средний | **нулевое** или **-i** | *źródeł, wydarzeń, narzędzi* |
| Нерегулярные | | *pieniądze → pieniędzy* |

> **Подсказка:** Мужской множ. → почти всегда **-ów**. Женский множ. → часто нулевое окончание (основа без -a). Средний множ. → нулевое или **-i**.

## Сравнение с русским

| Русский | Польский | Пример |
|---------|----------|--------|
| кризис**а** | kryzysu | *Без кризиса = Bez kryzysu* |
| власт**и** | władzy | *Концентрация власти = Koncentracja władzy* |
| свобод**ы** | wolności | *Потеря свободы = Utrata wolności* |
| событи**й** | wydarzeń | *Поток событий = Potok wydarzeń* |
| денег | pieniędzy | *Много денег = Dużo pieniędzy* |
| империи (не меняется) | imperium (не меняется) | *Падение империи = Upadek imperium* |

## Примеры в контексте (из Lekcji 6)

1. *Bez **kryzysu** nie ma zmian.* — Без кризиса нет изменений.
2. *Podczas **pandemii** miliarderzy zbogacieli.* — Во время пандемии миллиардеры разбогатели.
3. *To początek **upadku** **imperium**.* — Это начало упадка империи.
4. *Nie mamy **zaufania** do instytucji.* — У нас нет доверия к институтам.
5. *Dla **miliarderów** kryzys to możliwość.* — Для миллиардеров кризис — это возможность.
6. *Z różnych **źródeł** widać jeden obraz.* — Из разных источников видна одна картина.
7. *Dużo **pieniędzy**, ale mało **wolności**.* — Много денег, но мало свободы.
8. *Historia **imperiów** się powtarza.* — История империй повторяется.

## Частые ошибки

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| *Nie ma kryzys.* | *Nie ma kryzysu.* | После *nie ma* нужен Dopełniacz |
| *Bez wolność.* | *Bez wolności.* | После *bez* нужен Dopełniacz |
| *Dużo pieniądze.* | *Dużo pieniędzy.* | После *dużo* нужен Dopełniacz множ. числа |
| *Upadek imperia.* | *Upadek imperium.* | Средний род на *-um* не меняется в Dopełniaczu |
| *Historia imperiów.* ✅ | Правильно! | Множ. число: *imperia → imperiów* |
| *Brak zaufanie.* | *Brak zaufania.* | После *brak* нужен Dopełniacz |

---

## Связь с другими падежами

- **Biernik + отрицание → Dopełniacz:** *Widzę **wzorzec** (B)* → *Nie widzę **wzorca** (D)*
- **Dopełniacz vs Celownik:** *Upadek **imperium** (D, принадлежность)* vs *Daję **imperatorowi** (C, адресат)*
- **Dopełniacz vs Narzędnik:** *Bez **kryzysu** (D)* vs *Zarządzam **kryzysem** (N)*
