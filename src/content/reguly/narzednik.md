## Вопросы: Kim? Czym?

Narzędnik — падеж инструмента и роли. Отвечает на вопросы «кем?» и «чем?».

---

## Когда используется

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| *być* + Narzędnik | быть кем/чем | *Michels był członkiem SPD.* |
| *stać się* + Narzędnik | стать кем/чем | *Lider staje się zbawicielem.* |
| *zostać* + Narzędnik | стать кем/чем | *Został prezesem firmy.* |
| *zarządzać* + Narzędnik | управлять чем | *Zarządzać organizacją.* |
| *z* + Narzędnik | с кем/чем | *Rozmawia z liderami.* |
| *między* + Narzędnik | между кем/чем | *Między liderami a masą.* |
| *przed* + Narzędnik | перед кем/чем | *Przed domem rośnie drzewo.* |
| *nad* + Narzędnik | над кем/чем | *Pracuję nad projektem.* |
| *pod* + Narzędnik | под кем/чем | *Pod stołem leży kot.* |

> **Ключевое отличие от русского:** После *jest* (есть/является) ВСЕГДА Narzędnik. *On jest lekarzem* — Он врач. В русском Творительный здесь необязателен, в польском — обязателен.

---

## Окончания существительных

| Род / Тип | Окончание | Примеры |
|-----------|-----------|---------|
| Муж. (согласная) | *-em / -iem* | *socjolog → socjologiem, proces → procesem, student → studentem* |
| Муж. на -a | *-ą* | *socjalista → socjalistą, kolega → kolegą, kierowca → kierowcą* |
| Жен. на -a | *-ą* | *organizacja → organizacją, partia → partią, kobieta → kobietą* |
| Жен. на согласную | *-ą* | *noc → nocą, miłość → miłością* |
| Средний | *-em* | *prawo → prawem, społeczeństwo → społeczeństwem, miasto → miastem* |
| Мн. число (все роды) | *-ami* | *liderzy → liderami, kobiety → kobietami, miasta → miastami* |

> **Мн. число — просто:** почти всегда *-ami*. Исключения редки: *ludźmi* (от *ludzie*), *dziećmi* (от *dzieci*).

---

## Окончания прилагательных

| Род / Число | Окончание | Примеры |
|-------------|-----------|---------|
| Муж. / Сред. ед.ч. | *-ym / -im* | *demokratyczny → demokratycznym, duży → dużym, tani → tanim* |
| Жен. ед.ч. | *-ą* | *największa → największą, nowa → nową, polska → polską* |
| Мн. число | *-ymi / -imi* | *inni → innymi, nowi → nowymi, wielcy → wielkimi* |

---

## Полная таблица: Mianownik → Narzędnik

| Mianownik | Narzędnik | Перевод |
|-----------|-----------|---------|
| *dobry lekarz* | *dobrym lekarzem* | хороший врач |
| *polska organizacja* | *polską organizacją* | польская организация |
| *nowe prawo* | *nowym prawem* | новый закон |
| *młody socjalista* | *młodym socjalistą* | молодой социалист |
| *wielcy liderzy* | *wielkimi liderami* | великие лидеры |

---

## Примеры в контексте

1. *Michels był niemieckim socjologiem.* — Михельс был немецким социологом.
2. *Zarządzanie dużą organizacją jest trudne.* — Управление большой организацией — это сложно.
3. *Rozmawiam z moim bratem o polityce.* — Разговариваю с моим братом о политике.
4. *Między teorią a praktyką jest duża różnica.* — Между теорией и практикой большая разница.
5. *Została najlepszą studentką na roku.* — Стала лучшей студенткой на курсе.
6. *Piszę długopisem, a ty — ołówkiem.* — Я пишу ручкой, а ты — карандашом.

---

## Частые ошибки

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| *On jest lekarz.* | *On jest lekarzem.* | После *być* всегда Narzędnik |
| *Rozmawiam z liderzy.* | *Rozmawiam z liderami.* | Мн. число в Narzędniku: *-ami* |
| *z moim siostrą* | *z moją siostrą* | Жен. род прилагательного: *-ą*, не *-im* |
| *Zostałem dobry specjalista.* | *Zostałem dobrym specjalistą.* | После *zostać* — Narzędnik |

> **Подсказка для русскоговорящих:** Польский Narzędnik почти идентичен русскому Творительному. Окончания очень похожи: *-ем/-ом* → *-em*, *-ой/-ей* → *-ą*. Главное помнить — после *jest* он обязателен.
