## Что это такое

Каждый польский глагол принадлежит к одному из двух видов — точно так же, как в русском.

| Вид | По-польски | Сокращение | Вопрос | Русский аналог |
|-----|-----------|------------|--------|----------------|
| Несовершенный | *niedokonany* | **ndk** | *co robić?* | что делать? |
| Совершенный | *dokonany* | **dk** | *co zrobić?* | что сделать? |

**ndk** — процесс, повторение, привычка, факт без результата: *Wczoraj pisałem list.* (писал, неизвестно дописал ли)
**dk** — завершённое действие с результатом, одноразовое: *Wczoraj napisałem list.* (написал и закончил)

> **Хорошая новость для русскоговорящих:** система вида в польском устроена почти так же, как в русском. Если вы чувствуете разницу между «читал» и «прочитал» — вы уже чувствуете разницу между *czytałem* и *przeczytałem*. Ниже отмечены только те места, где интуиция подводит.

## Как образуются видовые пары

### 1. Приставка: ndk → dk (самый частый способ)

Приставка добавляется к несовершенному глаголу и делает его совершенным.

| ndk | dk | Приставка |
|-----|----|-----------|
| *pisać* | *napisać* | na- |
| *robić* | *zrobić* | z- |
| *czytać* | *przeczytać* | prze- |
| *jeść* | *zjeść* | z- |
| *pić* | *wypić* | wy- |
| *gotować* | *ugotować* | u- |
| *dzwonić* | *zadzwonić* | za- |
| *płacić* | *zapłacić* | za- |
| *prosić* | *poprosić* | po- |
| *czekać* | *poczekać* | po- |
| *sprzątać* | *posprzątać* | po- |
| *rozumieć* | *zrozumieć* | z- |

> Приставку **нельзя вывести логически** — её надо учить вместе с глаголом. Ровно как в русском: «писать → **на**писать», но «читать → **про**читать».

### 2. Суффикс: dk → ndk (обратное направление!)

Здесь базовый глагол — совершенный, а несовершенный образуется от него суффиксом *-wa-*, *-ywa-/-iwa-*, *-a-*.

| dk (база) | ndk (производный) |
|-----------|-------------------|
| *dać* | *dawać* |
| *sprzedać* | *sprzedawać* |
| *dostać* | *dostawać* |
| *wstać* | *wstawać* |
| *kupić* | *kupować* |
| *pokazać* | *pokazywać* |
| *podpisać* | *podpisywać* |
| *przygotować* | *przygotowywać* |
| *wrócić* | *wracać* |
| *zacząć* | *zaczynać* |
| *zapomnieć* | *zapominać* |
| *otworzyć* | *otwierać* |
| *wybrać* | *wybierać* |

### 3. Супплетивные пары (разные корни)

| ndk | dk |
|-----|----|
| *brać* | *wziąć* |
| *mówić* | *powiedzieć* |
| *widzieć* | *zobaczyć* |
| *oglądać* | *obejrzeć* |
| *kłaść* | *położyć* |
| *siadać* | *usiąść* |
| *szukać* | *znaleźć* |

> *Brać → wziąć* — точная калька русского «брать → взять». *Szukać → znaleźć* = «искать → найти». Эти пары можно не учить, они уже в голове.

## КРИТИЧЕСКОЕ ПРАВИЛО: у dk нет настоящего времени

Совершенный глагол физически не может обозначать «сейчас». Если он спрягается по образцу настоящего времени — это **будущее время**.

| Форма | Что это | Перевод |
|-------|---------|---------|
| *piszę* (ndk) | настоящее | пишу |
| *napiszę* (dk) | **будущее** | напишу |
| *robię* (ndk) | настоящее | делаю |
| *zrobię* (dk) | **будущее** | сделаю |
| *czytam* (ndk) | настоящее | читаю |
| *przeczytam* (dk) | **будущее** | прочитаю |

Отсюда следует главное: **у каждого вида своё будущее время**.

| Вид | Будущее | Пример |
|-----|---------|--------|
| dk | простое (спрягаем сам глагол) | *napiszę, zrobię, kupię* |
| ndk | составное (*być* + инфинитив / причастие) | *będę pisać / będę pisał* |

> Полный разбор: [⏩ Czas przyszły →](/polish-hub/reguly/czas-przyszly/)

> **Русская интуиция здесь работает на 100%:** «напишу» — тоже будущее, а «буду написать» по-русски невозможно. Ровно как *będę napisać* по-польски. Держитесь этого чувства.

## Что ещё нельзя сделать с dk-глаголом

| Конструкция | ndk | dk |
|-------------|-----|----|
| Настоящее время | *piszę* | ✗ невозможно |
| Составное будущее с *być* | *będę pisać* | ✗ *będę napisać* |
| Деепричастие на *-ąc* | *pisząc* | ✗ невозможно |
| После фазовых глаголов (*zacząć, przestać, skończyć*) | *zacząłem pisać* | ✗ *zacząłem napisać* |
| После *lubić, woleć, nienawidzić* | *lubię czytać* | ✗ *lubię przeczytać* |

Четыре запрета из пяти действуют и в русском («буду написать», «начал написать», «люблю прочитать» — так не говорят). Проверяйте себя переводом.

> **Исключение — деепричастие: здесь русский подводит.** По-русски совершенное деепричастие есть («сделав», «написав»), и перевод ошибку не поймает. По-польски формы *✗ zrobiąc, ✗ napisząc* не существует вообще: на *-ąc* образуются только ndk-глаголы (*robiąc, pisząc*). Совершенный аналог — *zrobiwszy, napisawszy* — архаика, на B1 не нужен.

## Маркеры времени: какое слово какой вид тянет

### → ndk (несовершенный)

| Маркер | Перевод | Пример |
|--------|---------|--------|
| *zawsze* | всегда | *Zawsze piję kawę rano.* |
| *często* | часто | *Często pisałem do niej.* |
| *rzadko* | редко | *Rzadko oglądam telewizję.* |
| *zwykle / zazwyczaj* | обычно | *Zwykle wracam o szóstej.* |
| *czasem / czasami* | иногда | *Czasem gotuję obiad.* |
| *codziennie* | ежедневно | *Codziennie uczę się polskiego.* |
| *co tydzień / co roku* | каждую неделю / год | *Co tydzień sprzątam mieszkanie.* |
| *długo* | долго | *Długo czekałem na odpowiedź.* |
| *cały dzień* | целый день | *Cały dzień pisałem raport.* |
| *godzinami* | часами | *Godzinami czytał tę książkę.* |
| *ciągle* | постоянно | *Ciągle zapominam hasła.* |
| *przez godzinę* | в течение часа | *Przez godzinę czytałem.* |

### → dk (совершенный)

| Маркер | Перевод | Пример |
|--------|---------|--------|
| *nagle* | вдруг | *Nagle zrozumiałem, o co chodzi.* |
| *wreszcie / w końcu* | наконец | *Wreszcie skończyłem projekt.* |
| *już* | уже | *Już napisałem ten list.* |
| *raz* | один раз | *Raz pojechałem do Gdańska.* |
| *od razu / natychmiast* | сразу | *Od razu zadzwoniłem do niej.* |
| *nareszcie* | наконец-то | *Nareszcie znalazłem klucze.* |
| *w godzinę / w ciągu godziny* | за час | *W godzinę napisałem raport.* |

> **Самая полезная пара маркеров:** *przez godzinę* (ndk) vs *w godzinę* (dk). Это польское «час» vs «за час»: *Przez godzinę pisałem list* — час писал. *W godzinę napisałem list* — за час написал. Логика русская.

## Вид после модальных глаголов

После *musieć, móc, chcieć, powinien, trzeba, można* идёт инфинитив — а вид выбираем по смыслу.

| Предложение | Вид | Почему |
|-------------|-----|--------|
| *Muszę napisać ten list.* | dk | одно конкретное дело, важен результат |
| *Muszę pisać codziennie.* | ndk | привычка, повторение |
| *Chcę zobaczyć ten film.* | dk | посмотреть один раз до конца |
| *Chcę oglądać filmy po polsku.* | ndk | вообще, регулярно |
| *Możesz otworzyć okno?* | dk | конкретная разовая просьба |
| *Można tu palić.* | ndk | общее разрешение, не разовое действие |

### При отрицании — почти всегда ndk

| Утверждение (dk) | Отрицание (ndk) |
|------------------|-----------------|
| *Musisz to zrobić.* | *Nie musisz tego robić.* |
| *Zrób to!* | *Nie rób tego!* |
| *Zamknij drzwi!* | *Nie zamykaj drzwi!* |
| *Trzeba to podpisać.* | *Nie trzeba tego podpisywać.* |

> Правило зеркалит русское: «Сделай это!» → «Не делай этого!». Совершенный вид под отрицанием звучит как предостережение («смотри не разбей»), а не как запрет.

## Польский vs русский: где интуиция подводит

### Ложные друзья

| Польский | НЕ значит | На самом деле | Русское слово по-польски |
|----------|-----------|---------------|--------------------------|
| *zapomnieć* | запомнить | **забыть** | запомнить = *zapamiętać* |
| *zapominać* | запоминать | **забывать** | запоминать = *zapamiętywać* |
| *zostać* | застать | **остаться** / **стать (кем-то)** | застать = *zastać* |
| *dostać* | достать | **получить** | достать (вынуть) = *wyjąć* |
| *obejrzeć* | обозреть | **посмотреть (фильм)** | — |
| *zdać egzamin* | сдавать экзамен | **сдать успешно** | сдавать (процесс) = *zdawać* |

> *Zapomniałem o spotkaniu* = «я забыл о встрече». Если хотели сказать «я запомнил» — это *zapamiętałem*. Ошибка меняет смысл на противоположный.

### Пары, где приставка другая, чем в русском

| Русский | Ожидаемое (✗) | Правильно (✓) |
|---------|---------------|---------------|
| увидеть | *uwidzieć* | *zobaczyć* |
| посмотреть (фильм) | *posmotrzeć* | *obejrzeć* |
| покупать | *pokupować* | *kupować* |
| сделать | *sdziełać* | *zrobić* |
| сказать | *skazać* (= осудить!) | *powiedzieć* |
| найти | *najść* (= нахлынуть) | *znaleźć* |

> *Skazać* по-польски — «приговорить», *najść* — «нахлынуть, нагрянуть». Прямой перенос русской приставки создаёт настоящее польское слово с чужим смыслом — это опаснее, чем несуществующее слово.

### Где вид работает одинаково — и это можно смело использовать

| Явление | Русский | Польский |
|---------|---------|----------|
| Пара «брать/взять» | брать / взять | *brać / wziąć* |
| Экзамен: процесс vs успех | сдавать / сдать | *zdawać / zdać* |
| Нет настоящего у dk | напишу = будущее | *napiszę* = будущее |
| Отрицание в императиве | не делай (нсв) | *nie rób* (ndk) |
| Фазовые глаголы | начал читать | *zacząłem czytać* |
| «за час» vs «час» | за час / час | *w godzinę / przez godzinę* |
| Определённое/неопределённое движение | идти / ходить | *iść / chodzić* |

## Частые ошибки

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| *Będę napisać list.* | *Napiszę list.* | У dk нет составного будущего — только простое |
| *Teraz zrobię obiad* (о текущем моменте) | *Teraz robię obiad.* | *Zrobię* — это «сделаю», будущее |
| *Zacząłem przeczytać książkę.* | *Zacząłem czytać książkę.* | После *zacząć / skończyć / przestać* — только ndk |
| *Codziennie napiszę e-maile.* | *Codziennie piszę e-maile.* | *Codziennie* = повторение → ndk |
| *Nie zamknij okna!* | *Nie zamykaj okna!* | Запрет — ndk |
| *Zapomniałem twój numer* в значении «запомнил» | *Zapamiętałem twój numer.* | *Zapomnieć* = забыть |
| *Lubię przeczytać książki.* | *Lubię czytać książki.* | После *lubić* — только ndk |
