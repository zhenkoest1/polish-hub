## Вопрос: O! (обращение)

Wołacz — падеж обращения. У него нет вопроса в обычном смысле: это форма, которой мы **окликаем** человека, а не форма члена предложения. Условный «вопрос» — междометие *o!*: *O Aniu!*

Два места, где он реально нужен:

1. **Прямое обращение** — окликаем, зовём, просим внимания: *Aniu, chodź tutaj!*
2. **Начало письма и e-maila** — *Szanowny Panie…*, *Droga Aniu…* Это прямо проверяется на экзамене B1 в письменной части.

## Мужской род — главный лайфхак

**Wołacz мужского рода почти всегда совпадает с miejscownikiem.** Знаете *o Marku* — знаете *Marku!* Отдельно учить нечего.

| Чем оканчивается основа | Окончание | Miejscownik → Wołacz |
|-------------------------|-----------|----------------------|
| Твёрдая: *p, b, f, w, m, n, s, z, t, d, r, ł* | **-e** + чередование | *o Adamie → Adamie!*, *o Piotrze → Piotrze!*, *o profesorze → profesorze!*, *o bracie → bracie!*, *o Pawle → Pawle!* |
| Мягкая: *ć, ś, ź, dź, ń, l, j* | **-u** | *o nauczycielu → nauczycielu!*, *o przyjacielu → przyjacielu!*, *o Andrzeju → Andrzeju!* |
| Отвердевшая: *c, dz, cz, dż, sz, ż, rz* | **-u** | *o lekarzu → lekarzu!*, *o mężu → mężu!*, *o Tomaszu → Tomaszu!* |
| Задненёбная: *k, g, ch* | **-u** | *o Marku → Marku!*, *o Wojtku → Wojtku!*, *o chłopaku → chłopaku!*, *o człowieku → człowieku!* |
| Особые на *-u* | **-u** | *o synu → synu!*, *o dziadku → dziadku!*, *o królu → królu!* |

Чередования перед *-e* те же, что в miejscowniku: *Piotr → Piotrze* (*r → rz*), *Paweł → Pawle* (*ł → l*), *brat → bracie* (*t → ci*), *Krzysztof → Krzysztofie* (*f → fi*), *sąsiad → sąsiedzie* (*d → dzi*, *a → e*).

### Исключения — где wołacz ≠ miejscownik

Их немного, но одно из них — самое частое слово в языке.

| Слово | Miejscownik | **Wołacz** | Комментарий |
|-------|-------------|------------|-------------|
| *pan* | *o panu* | ***panie!*** | ⚠️ Главное исключение. *Szanowny Panie*, а не *«Panu»* |
| *ojciec* | *o ojcu* | *ojcze!* | тип на *-ec* → *-cze* |
| *chłopiec* | *o chłopcu* | *chłopcze!* | то же |
| *Bóg* | *o Bogu* | *Boże!* | *Panie Boże!* |
| *ksiądz* | *o księdzu* | *księże!* | *Księże Janie* |
| Муж. род на *-a*: *kolega, tata, poeta* | *o koledze, o tacie* | *kolego! tato! poeto!* | склоняются как женский род → **-o** |

## Женский род

| Тип слова | Окончание | Примеры |
|-----------|-----------|---------|
| Обычные слова и полные имена на *-a* | **-o** | *Anna → Anno!*, *Marta → Marto!*, *Ewa → Ewo!*, *Katarzyna → Katarzyno!*, *mama → mamo!*, *siostra → siostro!*, *żona → żono!*, *matka → matko!*, *koleżanka → koleżanko!* |
| Ласкательные и уменьшительные (*-sia, -cia, -nia, -dzia, -la*) | **-u** | *Ania → Aniu!*, *Kasia → Kasiu!*, *Zosia → Zosiu!*, *Gosia → Gosiu!*, *Ola → Olu!*, *babcia → babciu!*, *ciocia → ciociu!*, *mamusia → mamusiu!* |
| Женский род на согласную | **-i / -y** (= dopełniacz) | *miłość → miłości!*, *noc → nocy!* |
| Слова на *-i* | **= mianownik** | *pani → Pani!*, *gospodyni → gospodyni!* |

> **Ключевая пара:** *-o* — нейтрально и формально, *-u* — тепло и по-домашнему. *Anno* — так обратится начальник в официальном письме; *Aniu* — так напишет подруга. Не *«Ano»* и не *«Aniо»*.

> Форма имени решает, а не мягкость основы: *Maria → Mario!* (полное имя, *-o*), но *Marysia → Marysiu!* (уменьшительное, *-u*).

## Средний род и все множественные числа

**Совпадают с mianownikiem. Учить нечего.**

| | Mianownik = Wołacz |
|---|---|
| Средний род | *dziecko → dziecko!*, *kochanie → kochanie!*, *słońce → słońce!* |
| Мн. число, муж.-личн. | *panowie → Panowie!*, *przyjaciele → Przyjaciele!*, *koledzy → Koledzy!* |
| Мн. число, остальные | *panie → Panie!*, *dziewczyny → dziewczyny!*, *dzieci → dzieci!* |
| *państwo* | *Państwo → Państwo!* (прилагательное — как муж.-личн.: *Szanowni Państwo*) |

## Прилагательные в wołaczu

**Прилагательное в wołaczu = прилагательное в mianowniku.** Меняется только существительное.

| Mianownik | Wołacz |
|-----------|--------|
| *szanowny pan* | *Szanowny **Panie*** |
| *szanowna pani* | *Szanowna **Pani*** |
| *droga Ania* | *Droga **Aniu*** |
| *kochana mama* | *Kochana **Mamo*** |
| *drodzy przyjaciele* | *Drodzy Przyjaciele* (оба слова без изменений) |

Это частая ошибка: в *Szanowny Panie Dyrektorze* прилагательное остаётся в mianowniku (*szanowny*), а оба существительных уходят в wołacz (*panie*, *dyrektorze*).

## Готовые формулы — выучить наизусть

| Формула | Когда |
|---------|-------|
| *Szanowni Państwo,* | официальное письмо, адресат неизвестен или это группа — **самый безопасный вариант на экзамене** |
| *Szanowna Pani,* / *Szanowny Panie,* | официально, к женщине / мужчине |
| *Szanowny Panie Dyrektorze,* | + должность: *Prezesie, Profesorze, Doktorze, Redaktorze* |
| *Szanowna Pani Dyrektor,* | ⚠️ женская должность **не склоняется**: *Pani Profesor*, *Pani Doktor* |
| *Szanowny Panie Marku,* / *Szanowna Pani Anno,* | полуофициально — коллега, преподаватель |
| *Drodzy Państwo,* | чуть теплее: выступление, рассылка |
| *Droga Aniu,* / *Drogi Marku,* | неофициальное письмо |
| *Kochana Mamo,* / *Kochani,* | письмо близким |
| *Cześć Aniu!* | e-mail другу |
| *proszę pana / proszę pani / proszę państwa* | устное обращение к незнакомому: *Przepraszam, proszę pani, która godzina?* |

> ***Proszę pana*** — это не wołacz, а **dopełniacz** после глагола *prosić*. Форма застыла, разбирать её не нужно — просто запомнить целиком.

> К мужчине по фамилии обращаются, оставляя фамилию в mianowniku: *Panie Kowalski*, *Panie Nowak*. Форма *«Panie Nowaku»* звучит грубовато.

## Wołacz в письме: запятая и следующая строка

Стандарт польского письма:

```
Szanowni Państwo,

zwracam się z prośbą o…
```

- После обращения — **запятая**, затем **пустая строка**, и текст начинается **с маленькой буквы**. Это традиционная норма, и на экзамене она безошибочна.
- Второй допустимый вариант — **восклицательный знак**, и тогда следующее слово **с большой буквы**: *Szanowni Państwo!* → *Zwracam się…*
- Вариант «запятая + большая буква» — калька с английского. Распространён, но на письменной части лучше его не использовать.

В тексте письма местоимения вежливости пишутся **с большой буквы**: *Pan, Pani, Państwo, Ty, Ciebie, Twój, Wam* — *Dziękuję Panu za odpowiedź*, *Czekam na Twój list*.

> ***Witam*** — не нейтральное приветствие. Так пишет тот, кто «принимает у себя»: к преподавателю, начальнику или в учреждение это невежливо. Берите *Szanowni Państwo* или *Dzień dobry*.

## Устная речь: wołacz часто заменяют на mianownik

В разговорном польском обращение всё чаще идёт в mianowniku:

- *Marek, chodź!* (вместо *Marku, chodź!*)
- *Kasia, zaczekaj!* (вместо *Kasiu, zaczekaj!*)

Это живая норма разговорной речи, не ошибка.

**Но wołacz остаётся обязательным:**

| Где обязательно | Пример |
|-----------------|--------|
| В письмах и e-mailах | *Szanowny Panie Dyrektorze* |
| В формулах с *pan / pani / państwo* | *proszę pana*, *Panie Kowalski* |
| С должностями и титулами | *Panie Profesorze*, *Księże Janie* |
| В обращении к родным и в ласковых формах | *Mamo!*, *Aniu!*, *Kochanie!* |
| В эмоциональных возгласах | *Boże!*, *Człowieku, co ty robisz?* |

> Вывод для экзамена: в разговоре можно не думать, **в письме — думать обязательно**. Замена *Szanowny Panie* на *«Szanowny Pan»* — это ошибка, а не разговорный стиль.

---

## Примеры в контексте

1. *Szanowni Państwo, piszę w sprawie mojego wniosku.* — Уважаемые дамы и господа, пишу по поводу моего заявления.
2. *Droga Aniu, dziękuję za zaproszenie na wesele.* — Дорогая Аня, спасибо за приглашение на свадьбу.
3. *Panie Marku, czy może Pan przesłać mi ten dokument?* — Пан Марек, вы могли бы прислать мне этот документ?
4. *Przepraszam, proszę pani, gdzie jest dworzec?* — Извините, пани, где вокзал?
5. *Mamo, tato, wracam do domu w piątek!* — Мама, папа, я возвращаюсь домой в пятницу!
6. *Szanowna Pani Profesor, chciałbym zapytać o termin egzaminu.* — Уважаемая пани профессор, хотел бы спросить о дате экзамена.
7. *Kochani, dziękuję Wam za wszystko.* — Дорогие мои, спасибо вам за всё.

## Частые ошибки

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| *Szanowny Pan,* | *Szanowny Panie,* | *pan* — исключение: wołacz *panie*, хотя miejscownik *panu* |
| *Szanowny Panu,* | *Szanowny Panie,* | *panu* — это miejscownik/celownik, не обращение |
| *Szanowny Panie Dyrektor,* | *Szanowny Panie Dyrektorze,* | должность тоже уходит в wołacz |
| *Szanowna Pani Dyrektorko,* | *Szanowna Pani Dyrektor,* | женская должность после *Pani* не склоняется |
| *Szanownym Panie,* | *Szanowny Panie,* | прилагательное в wołaczu = mianownik |
| *Droga Ania,* | *Droga Aniu,* | уменьшительное имя → *-u* |
| *Anno* подруге в чате | *Aniu* | *-o* формально и звучит холодно |
| *Kochana Mama,* | *Kochana Mamo,* | обычное слово на *-a* → *-o* |
| *Szanowni Państwo, Piszę…* | *Szanowni Państwo,* + *piszę…* | после запятой — с маленькой буквы |
| *Kolego* → *«Koledze»* | *Kolego!* | муж. род на *-a* склоняется как женский |
| *Ojcu!* | *Ojcze!* | тип на *-ec* даёт *-cze* |
| *Witam Panie Profesorze* | *Szanowny Panie Profesorze* | *Witam* невежливо к вышестоящему |

> **Подсказка для русскоговорящих:** в русском звательного падежа нет — остались только осколки («Боже», «отче», «мам!»). Поэтому мозг по умолчанию ставит именительный, и в разговоре это сойдёт с рук. На письме — нет. Практический минимум для B1: *Szanowni Państwo*, *Szanowny Panie*, *Szanowna Pani*, *proszę pana / pani* и правило «*-o* формально / *-u* ласково» для женских имён.

## Связь с другими падежами

- **Wołacz = Miejscownik** в мужском роде: выучили *o Marku, o profesorze, o synu* — получили *Marku! Profesorze! Synu!* Исключения: *pan → panie*, *ojciec → ojcze*, *chłopiec → chłopcze*, *Bóg → Boże*, *ksiądz → księże*.
- **Wołacz = Mianownik** в среднем роде, во всём множественном числе и у всех прилагательных.
- **Женский род** — единственное место, где нужна собственная форма: *-o* или *-u*.
