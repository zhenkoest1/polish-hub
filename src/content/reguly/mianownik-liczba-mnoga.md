## Вопросы: Kto? Co?

Mianownik — исходная, словарная форма. Это то, что вы видите в словаре, и то, чем в предложении выражено **подлежащее**.

| Функция | Пример |
|---------|--------|
| Подлежащее | ***Student** czyta książkę.* |
| Именная часть после *to (jest / są)* | *To jest **nauczyciel**.* |
| Название, подпись, заголовок | *«**Zbrodnia i kara**» — powieść Dostojewskiego.* |

Сам по себе Mianownik трудностей не создаёт. Настоящая тема этой страницы — **множественное число**, которое на B1 ломается чаще всего.

---

## Ловушка №1: *jest* + Narzędnik, но *to jest* + Mianownik

Классическая ошибка. Оба предложения переводятся «Он учитель», но падежи разные.

| Конструкция | Падеж | Пример |
|-------------|-------|--------|
| подлежащее + *być* + **существительное** | Narzędnik | *On jest **nauczycielem**.* |
| *To jest / To są* + существительное | Mianownik | *To jest **nauczyciel**.* |
| подлежащее + *być* + **только прилагательное** | Mianownik | *On jest **wysoki**.* |
| подлежащее + *być* + прилагательное + существительное | Narzędnik (оба слова) | *On jest **wysokim nauczycielem**.* |

- *To jest **moja siostra**.* — но *Ona jest **moją siostrą**.*
- *To są **dobrzy studenci**.* — но *Oni są **dobrymi studentami**.*
- *Ona jest **młoda**.* (прил. одно → Mianownik) — но *Ona jest **młodą kobietą**.*

> **Правило в одну строку:** если перед именем стоит *to* — Mianownik. Если подлежащее — местоимение или существительное (*on, ona, Marek*), а после *jest* идёт существительное — Narzędnik.

## Главное деление во множественном числе: męskoosobowy vs niemęskoosobowy

В единственном числе в польском три рода. Во множественном их фактически **два**:

| Род во мн. числе | Что входит | Местоимение |
|------------------|------------|-------------|
| **Męskoosobowy** (мужско-личный) | только мужчины-люди: *studenci, panowie, Polacy, ludzie, bracia* | *oni* |
| **Niemęskoosobowy** (немужско-личный) | всё остальное: женщины, дети, животные, вещи, абстракции | *one* |

> **Ключевое:** если в группе есть **хотя бы один мужчина** — вся группа męskoosobowa. Сто женщин и один мужчина → *oni byli*. Женщины без мужчин → *one były*. Логики в этом искать не надо, это грамматика, а не социология.

От этого выбора зависят три вещи сразу: окончание существительного, окончание прилагательного и форма глагола в прошедшем времени.

| | Męskoosobowy | Niemęskoosobowy |
|---|---|---|
| Существительное | *studenci* | *studentki* |
| Прилагательное | *dobrzy* | *dobre* |
| Глагол (прош. вр.) | *byli, czytali* | *były, czytały* |
| Указательное «эти» | *ci* | *te* |
| «Мои» | *moi* | *moje* |
| Полная фраза | *Ci dobrzy studenci byli tutaj.* | *Te dobre studentki były tutaj.* |

## Окончания существительных — множественное число

### Męskoosobowy (мужчины-люди)

| Окончание | Когда | Примеры |
|-----------|-------|---------|
| **-i** (с чередованием) | после твёрдой согласной | *student → studenci, Szwed → Szwedzi, sąsiad → sąsiedzi* |
| **-y** | после отвердевших *c, dz, rz* (в том числе возникших из чередования) | *Polak → Polacy, chłopiec → chłopcy, aktor → aktorzy* |
| **-e** | после мягкой согласной, а также в словах на *-arz, -erz, -el, -j, -an* | *lekarz → lekarze, nauczyciel → nauczyciele, gość → goście, złodziej → złodzieje, Hiszpan → Hiszpanie* |
| **-owie** | титулы, родство, уважение | *pan → panowie, syn → synowie, ojciec → ojcowie* |

### Męskorzeczowy / -zwierzęcy (мужской неличный: вещи и животные)

| Окончание | Когда | Примеры |
|-----------|-------|---------|
| **-y** | после твёрдой согласной | *dom → domy, telefon → telefony, kot → koty, samochód → samochody, stół → stoły* |
| **-i** | после *k, g* | *ptak → ptaki, bank → banki, pociąg → pociągi, róg → rogi* |
| **-e** | после мягкой и отвердевшей согласной | *pokój → pokoje, klucz → klucze, koń → konie, nóż → noże, hotel → hotele* |

### Женский род

| Окончание | Когда | Примеры |
|-----------|-------|---------|
| **-y** | *-a* после твёрдой согласной | *kobieta → kobiety, szkoła → szkoły, siostra → siostry, mapa → mapy* |
| **-i** | *-a* после *k, g* | *książka → książki, matka → matki, córka → córki, noga → nogi* |
| **-e** | *-a* после мягкой и отвердевшей согласной | *ulica → ulice, praca → prace, lekcja → lekcje, kuchnia → kuchnie* |
| **-e / -y / -i** | оканчивающиеся на согласную | *noc → noce, twarz → twarze, rzecz → rzeczy, mysz → myszy, kość → kości* |
| **-ości** | все на *-ość* | *wiadomość → wiadomości, możliwość → możliwości* |

### Средний род

| Окончание | Когда | Примеры |
|-----------|-------|---------|
| **-a** | практически всегда | *okno → okna, miasto → miasta, mieszkanie → mieszkania, zdjęcie → zdjęcia* |
| **-a** | на *-um* (в ед. ч. не склоняется, во мн. — склоняется) | *muzeum → muzea, centrum → centra* |

> **Средний род — самый лёгкий:** во множественном числе всегда *-a*. И всегда niemęskoosobowy.

## Чередования согласных перед *-i* в męskoosobowym

Окончание *-i* смягчает предшествующую согласную. Это не исключения — это система. Выучив таблицу, вы перестанете угадывать.

| Чередование | Mianownik ед. ч. | Mianownik мн. ч. |
|-------------|------------------|------------------|
| **t → ci** | *student, Chorwat* | *studenci, Chorwaci* |
| **d → dzi** | *Szwed, sąsiad* | *Szwedzi, sąsiedzi* (+ *a → e*) |
| **st → ści** | *artysta, turysta, dentysta* | *artyści, turyści, dentyści* |
| **k → cy** | *Polak, robotnik, urzędnik* | *Polacy, robotnicy, urzędnicy* |
| **g → dzy** | *Norweg, biolog, kolega* | *Norwedzy, biolodzy, koledzy* |
| **r → rzy** | *aktor, autor, dyrektor* | *aktorzy, autorzy, dyrektorzy* |
| **ch → si** | *Włoch, Czech* | *Włosi, Czesi* |
| **z → zi** | *Francuz* | *Francuzi* |
| **n → ni** | *Hiszpan* | *Hiszpanie* |
| **-ec → -cy** (*e* выпадает) | *chłopiec, Niemiec, kupiec* | *chłopcy, Niemcy, kupcy* |
| нерегулярное | *brat* | *bracia* |

> **Внимание:** чередование срабатывает **только в męskoosobowym**. *Polak → Polacy* (мужчины), но *Polka → Polki* (женщины) — там никакого смягчения нет.

## Когда нужно *-owie*

Окончание *-owie* — «почётное». Оно выделяет три группы:

| Группа | Примеры |
|--------|---------|
| Титулы и обращения | *pan → panowie, król → królowie, minister → ministrowie* |
| Родство | *syn → synowie, ojciec → ojcowie, mąż → mężowie, dziadek → dziadkowie, wujek → wujkowie* |
| Звания и уважение | *profesor → profesorowie, uczeń → uczniowie, inżynier → inżynierowie* |
| Фамилии (вся семья) | *Nowak → Nowakowie, Kwiatkowski → Kwiatkowscy* |

- *Państwo Nowakowie mieszkają obok.* — Новаки живут рядом.
- *Moi synowie już studiują.* — Мои сыновья уже учатся.

> У части слов допустимы обе формы: *profesorowie* и *profesorzy*, *biolodzy* и *biologowie*. Ошибкой не будет ни то, ни другое.

## Прилагательные во множественном числе

| Род | Окончание | Примеры |
|-----|-----------|---------|
| **Męskoosobowy** | *-i / -y* + чередование | *dobrzy studenci, wysocy mężczyźni* |
| **Niemęskoosobowy** | *-e* | *dobre książki, wysokie domy* |

### Чередования в прилагательных

| Чередование | Niemęskoosobowy | Męskoosobowy |
|-------------|-----------------|--------------|
| **r → rz** | *dobre, stare* | *dobrzy, starzy* |
| **k → c** | *wysokie, wielkie* | *wysocy, wielcy* |
| **g → dz** | *drogie, ubogie* | *drodzy, ubodzy* |
| **sk → sc** | *polskie, ludzkie* | *polscy, ludzcy* |
| **d → dz** | *młode* | *młodzi* |
| **t → c** | *bogate* | *bogaci* |
| **ł → l** | *miłe, wesołe* | *mili, weseli* |
| **ż → z** | *duże* | *duzi* |
| **sz → s** | *pierwsze* | *pierwsi* |
| **n → ni** | *inteligentne* | *inteligentni* |
| **w → wi** | *zdrowe, ciekawe* | *zdrowi, ciekawi* |
| без изменений (мягкие) | *tanie, głupie, ostatnie* | *tani, głupi, ostatni* |

### Определители тоже делятся

| Ед. ч. | Męskoosobowy | Niemęskoosobowy |
|--------|--------------|-----------------|
| *ten / ta / to* | *ci* | *te* |
| *mój / moja* | *moi* | *moje* |
| *twój* | *twoi* | *twoje* |
| *nasz* | *nasi* | *nasze* |
| *wasz* | *wasi* | *wasze* |
| *jaki* | *jacy* | *jakie* |
| *który* | *którzy* | *które* |
| *wszystek* | *wszyscy* | *wszystkie* |
| *on / ona / ono* | *oni* | *one* |

- *Ci moi nowi koledzy…* — Эти мои новые коллеги (мужчины)…
- *Te moje nowe koleżanki…* — Эти мои новые коллеги (женщины)…

## Глагол в прошедшем времени: *-li* или *-ły*

В настоящем времени разницы нет: *oni czytają / one czytają*. В **прошедшем** — есть, и обязательная.

| Męskoosobowy: *-li* | Niemęskoosobowy: *-ły* |
|---------------------|------------------------|
| *Chłopcy **byli** w szkole.* | *Dziewczyny **były** w szkole.* |
| *Studenci **czytali** książki.* | *Studentki **czytały** książki.* |
| *Oni **mieli** czas.* | *One **miały** czas.* |
| *Moi bracia **poszli** do kina.* | *Moje siostry **poszły** do kina.* |
| *Ludzie **mówili** o tym.* | *Dzieci **mówiły** o tym.* |
| *Panowie **pracowali** cały dzień.* | *Koty **spały** cały dzień.* |

> То же деление действует в сослагательном наклонении (*byliby / byłyby*) и в страдательных формах (*zostali zaproszeni / zostały zaproszone*).

## Нерегулярное множественное число

Список короткий — выучить целиком реально.

| Ед. ч. | Мн. ч. | Род во мн. ч. | Пример |
|--------|--------|---------------|--------|
| *człowiek* | *ludzie* | męskoosobowy | *Ci ludzie byli mili.* |
| *rok* | *lata* | niemęskoosobowy | *Minęły dwa lata.* |
| *dziecko* | *dzieci* | niemęskoosobowy | *Te dzieci były głodne.* |
| *ręka* | *ręce* | niemęskoosobowy | *Ręce mi zmarzły.* |
| *oko* | *oczy* | niemęskoosobowy | *Jej oczy były zielone.* |
| *ucho* | *uszy* | niemęskoosobowy | *Uszy mnie bolały.* |
| *brat* | *bracia* | męskoosobowy | *Moi bracia przyjechali.* |
| *ksiądz* | *księża* | męskoosobowy | *Księża czekali przed kościołem.* |
| *przyjaciel* | *przyjaciele* | męskoosobowy | *Nasi przyjaciele pomogli.* |
| *tydzień* | *tygodnie* | niemęskoosobowy | *Minęły trzy tygodnie.* |
| *imię* | *imiona* | niemęskoosobowy | *Te imiona są rzadkie.* |
| *zwierzę* | *zwierzęta* | niemęskoosobowy | *Zwierzęta uciekły.* |
| *Amerykanin* | *Amerykanie* | męskoosobowy | *Amerykanie przyjechali.* |
| *Rosjanin* | *Rosjanie* | męskoosobowy | *Rosjanie mówili po polsku.* |

> Тип **-anin → -anie** регулярен и покрывает названия жителей стран и городов: *Rosjanin → Rosjanie, Amerykanin → Amerykanie, Egipcjanin → Egipcjanie, krakowianin → krakowianie*. Все они męskoosobowe.

## Бонус: числительные и męskoosobowy

Самое частое практическое последствие мужско-личного рода.

| Тип | Конструкция | Пример |
|-----|-------------|--------|
| Męskoosobowy, 2–4 | *dwaj / trzej / czterej* + Mianownik мн. ч. | *Dwaj studenci przyszli.* |
| Męskoosobowy, 2–4 (частотный вариант) | *dwóch / trzech / czterech* + Dopełniacz, глагол в форме ср. рода ед. ч. | *Dwóch studentów przyszło.* |
| Męskoosobowy, 5+ | *pięciu / sześciu…* + Dopełniacz, глагол ср. рода ед. ч. | *Pięciu studentów przyszło.* |
| Niemęskoosobowy, 2–4 | *dwie / trzy / cztery* + Mianownik мн. ч. | *Dwie kobiety przyszły.* |
| Niemęskoosobowy, 5+ | *pięć / sześć…* + Dopełniacz, глагол ср. рода ед. ч. | *Pięć kobiet przyszło.* |

> Обратите внимание на глагол: *przyszli* (полное согласование) против *przyszło* (безличная форма среднего рода). Второе — не ошибка, а норма при количественной конструкции.

## Частые ошибки

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| *On jest nauczyciel.* | *On jest nauczycielem.* / *To jest nauczyciel.* | После *być* + существительное — Narzędnik; после *to jest* — Mianownik |
| *Polaki* | *Polacy* | Męskoosobowy: *k → cy* |
| *dobre studenci* | *dobrzy studenci* | Прилагательное при męskoosobowym: *-i/-y* с чередованием |
| *studenci były* | *studenci byli* | Męskoosobowy в прош. вр. — *-li* |
| *ludzie były* | *ludzie byli* | *ludzie* — męskoosobowy, несмотря на нерегулярную форму |
| *dzieci byli* | *dzieci były* | *dzieci* — niemęskoosobowy |
| *te studenci* | *ci studenci* | Указательное при męskoosobowym — *ci* |
| *moje bracia* | *moi bracia* | Притяжательное при męskoosobowym — *moi* |
| *dwa lata były* | *minęły dwa lata* | *lata* — niemęskoosobowy: *-ły* |
| *Polacy* о группе женщин | *Polki* | Чередование *k → cy* только для мужчин: *Polak → Polacy*, но *Polka → Polki* |
| *człowieki / człowiekowie* | *ludzie* | Нерегулярная форма, других нет |

> **Подсказка для русскоговорящих:** в русском категории «мужско-личного рода» нет вообще — «студенты были» и «книги были» устроены одинаково. Именно поэтому *studenci byli / książki były* приходится держать в голове сознательно. Спрашивайте себя перед каждым множественным числом: **«есть ли там хотя бы один мужчина?»**
