## Зачем эта страница

Падежи бесполезны, пока не знаешь, какой предлог какого падежа требует. Предлог в польском — жёсткий: он **всегда** тянет за собой один и тот же падеж (а если два — то значение меняется).

Сокращения в таблицах: **D** — dopełniacz, **C** — celownik, **B** — biernik, **N** — narzędnik, **Ms** — miejscownik.

---

## Главная таблица: предлоги по падежам

### Dopełniacz (kogo? czego?) — самая большая группа

| Предлог | Значение | Пример |
|---------|----------|--------|
| *do* | в, к, до | *Idę do szkoły.* |
| *od* | от, с (времени) | *Czekam od rana.* |
| *z / ze* | из, с (откуда) | *Wracam z pracy.* |
| *bez* | без | *Kawa bez cukru.* |
| *dla* | для | *To prezent dla ciebie.* |
| *u* | у (в гостях, в кабинете) | *Byłem u lekarza.* |
| *obok* | рядом с | *Mieszkam obok parku.* |
| *koło* | около, возле | *Spotkajmy się koło kina.* |
| *według* | по мнению, согласно | *Według mnie to błąd.* |
| *podczas* | во время | *Podczas lekcji nie rozmawiamy.* |
| *oprócz* | кроме | *Wszyscy oprócz Anny.* |
| *wśród* | среди | *Wśród ludzi czuję się dobrze.* |
| *naprzeciwko* | напротив | *Bank jest naprzeciwko poczty.* |
| *zamiast* | вместо | *Zamiast kawy piję herbatę.* |
| *mimo* | несмотря на | *Mimo deszczu wyszliśmy.* |

### Celownik (komu? czemu?) — их всего четыре

| Предлог | Значение | Пример |
|---------|----------|--------|
| *dzięki* | благодаря | *Dzięki tobie zdałem egzamin.* |
| *przeciwko / przeciw* | против | *Głosowałem przeciwko tej ustawie.* |
| *wbrew* | вопреки | *Wbrew pozorom to proste.* |
| *ku* | к, по направлению к | *Szliśmy ku morzu.* |

> Четыре предлога — выучить целиком, это самая дешёвая победа на экзамене.

### Biernik (kogo? co?)

| Предлог | Значение | Пример |
|---------|----------|--------|
| *przez* | через; в течение; из-за | *Idę przez most. Uczyłem się przez godzinę.* |
| *na* + B | на (куда), для, на срок | *Idę na koncert. Jadę na tydzień.* |
| *w* + B | в (день недели), в (игру) | *W środę mam egzamin. Gram w piłkę.* |
| *o* + B | о (просить, спрашивать) | *Pytam o drogę. Proszę o pomoc.* |
| *po* + B | за (чем-то сходить) | *Idę po chleb.* |
| *za* + B | через (о будущем времени) | *Wrócę za godzinę.* |
| *nad, pod, przed, za, między* + B | **направление движения** | *Jadę nad morze. Wszedł pod stół.* |

### Narzędnik (kim? czym?)

| Предлог | Значение | Пример |
|---------|----------|--------|
| *z / ze* | с (вместе, вместе с чем-то) | *Idę z bratem. Kawa z mlekiem.* |
| *nad* | над (где) | *Mieszkam nad morzem.* |
| *pod* | под (где) | *Kot śpi pod stołem.* |
| *przed* | перед (где; до какого времени) | *Czekam przed domem. Przed obiadem.* |
| *za* | за (где) | *Ogród jest za domem.* |
| *między / pomiędzy* | между | *Między domem a szkołą.* |
| *poza* | за пределами | *Mieszkam poza miastem.* |

### Miejscownik (o kim? o czym?) — только с предлогами

| Предлог | Значение | Пример |
|---------|----------|--------|
| *w / we* | в (где) | *Jestem w domu. Mieszkam we Wrocławiu.* |
| *na* + Ms | на (где) | *Książka leży na stole.* |
| *o* + Ms | о (рассказывать, думать) | *Mówimy o pracy. Myślę o tobie.* |
| *po* + Ms | после; по (территории) | *Po obiedzie. Chodzę po Warszawie.* |
| *przy* | у, рядом, при | *Siedzę przy stole.* |

> **Miejscownik без предлога не существует.** Если видите *w, na, o, po, przy* — проверьте, не Ms ли это.

## Главная развилка: движение vs местонахождение

Это ошибка №1 у всех, кто учит польский. Один и тот же предлог меняет падеж в зависимости от того, есть движение или нет.

### Триада «куда — где — откуда»

| Куда? (dokąd?) | Где? (gdzie?) | Откуда? (skąd?) |
|-----------------|----------------|------------------|
| *do szkoły* (D) | *w szkole* (Ms) | *ze szkoły* (D) |
| *do Polski* (D) | *w Polsce* (Ms) | *z Polski* (D) |
| *na pocztę* (B) | *na poczcie* (Ms) | *z poczty* (D) |
| *na Ukrainę* (B) | *na Ukrainie* (Ms) | *z Ukrainy* (D) |
| *do lekarza* (D) | *u lekarza* (D) | *od lekarza* (D) |
| *nad morze* (B) | *nad morzem* (N) | *znad morza* (D) |
| *pod stół* (B) | *pod stołem* (N) | *spod stołu* (D) |
| *za dom* (B) | *za domem* (N) | *zza domu* (D) |
| *przed dom* (B) | *przed domem* (N) | *sprzed domu* (D) |

> **Логика:** «куда» = biernik (или *do* + D), «где» = miejscownik или narzędnik, «откуда» = всегда dopełniacz.

### nad, pod, przed, za, między: B при движении, N в покое

| Движение → **Biernik** | Покой → **Narzędnik** |
|-------------------------|------------------------|
| *Jadę **nad morze**.* | *Jestem **nad morzem**.* |
| *Kot wszedł **pod stół**.* | *Kot leży **pod stołem**.* |
| *Wyszedłem **przed dom**.* | *Stoję **przed domem**.* |
| *Jedziemy **za miasto**.* | *Mieszkamy **za miastem**.* |
| *Postawiłem krzesło **między stół a szafę**.* | *Krzesło stoi **między stołem a szafą**.* |

> С *między* в bierniku части соединяются через ***a***: *między stół **a** szafę*. В narzędniku тоже обычно *a*: *między stołem **a** szafą*.

### na i w: B при движении, Ms в покое

| Движение → **Biernik** | Покой → **Miejscownik** |
|-------------------------|--------------------------|
| *Kładę książkę **na stół**.* | *Książka leży **na stole**.* |
| *Idę **na uniwersytet**.* | *Jestem **na uniwersytecie**.* |
| *Wchodzę **w las**.* | *Jestem **w lesie**.* |

> **Важно:** для «войти внутрь» польский почти всегда предпочитает *do* + D, а не *w* + B: *Wchodzę **do** pokoju*, *Wkładam książkę **do** torby*. Конструкция *w* + B в значении движения — редкая и книжная.

### do czy na? — куда именно

| *do* + Dopełniacz | *na* + Biernik |
|--------------------|-----------------|
| закрытые помещения, города, страны | мероприятия, открытые площадки, «плоские» места |
| *idę do parku* | *idę na koncert* |
| *idę do kina* | *idę na film* |
| *idę do szkoły* (учиться) | *idę na lekcję* (на конкретный урок) |
| *jadę do Krakowa* | *jadę na wieś* |
| *idę do restauracji* | *idę na obiad* |
| *idę do biblioteki* | *idę na pocztę* |

## w czy na? — места и учреждения

Здесь **логики почти нет** — это списки, которые заучивают. Правило «*na* для открытых пространств» работает процентов на шестьдесят и ломается на *na poczcie* и *na uniwersytecie*.

| *na* + Miejscownik | *w* + Miejscownik |
|---------------------|--------------------|
| *na poczcie* | *w banku* |
| *na uniwersytecie*, *na uczelni* | *w szkole*, *w przedszkolu* |
| *na dworcu*, *na lotnisku*, *na stacji* | *w domu*, *w mieszkaniu* |
| *na wsi* | *w mieście* |
| *na ulicy*, *na rynku*, *na placu* | *w parku*, *w ogrodzie* |
| *na plaży*, *na basenie* | *w kinie*, *w teatrze* |
| *na koncercie*, *na imprezie*, *na weselu* | *w restauracji*, *w kawiarni* |
| *na wykładzie*, *na lekcji*, *na spotkaniu* | *w pracy*, *w biurze* |
| *na policji*, *na komisariacie* | *w szpitalu*, *w aptece* |
| *na wakacjach*, *na urlopie* | *w bibliotece*, *w muzeum* |

### Страны и регионы

| *w* — большинство стран | *na* — острова и «исторические соседи» |
|--------------------------|------------------------------------------|
| *w Polsce*, *w Niemczech*, *we Francji* | *na Węgrzech*, *na Litwie*, *na Łotwie* |
| *w Rosji*, *w Czechach*, *w Hiszpanii* | *na Białorusi*, *na Słowacji*, *na Ukrainie* |
| *w Wielkiej Brytanii*, *we Włoszech* | *na Malcie*, *na Cyprze*, *na Islandii*, *na Kubie* |

**Города — всегда *w*:** *w Warszawie, w Krakowie, we Wrocławiu, w Gdańsku, w Poznaniu, w Łodzi*.

**Регионы Польши смешанные:** *na Śląsku, na Mazowszu, na Pomorzu, na Mazurach, na Kaszubach* — но *w Małopolsce, w Wielkopolsce*.

> **Про Украину честно:** традиционная норма — *na Ukrainie / na Ukrainę / z Ukrainy*. После 2022 года форма *w Ukrainie* стала массовой и признаётся допустимой. На экзамене безопаснее *na Ukrainie* — это форма, которая точно есть во всех учебниках.

## Один предлог — два падежа

### z / ze: «из» или «с»?

Одно слово, два разных падежа, два разных значения.

| Значение | Падеж | Пример |
|----------|-------|--------|
| **из, с** (откуда) | Dopełniacz | *Wyszedł **z domu**.* — Вышел из дома. |
| **с** (вместе) | Narzędnik | *Wyszedł **z bratem**.* — Вышел с братом. |

Ещё пары:

| Dopełniacz (откуда / из чего) | Narzędnik (с чем) |
|--------------------------------|--------------------|
| *Jestem **z Polski**.* | *Rozmawiam **z Polakiem**.* |
| *Sok **z pomarańczy**.* (из апельсинов) | *Herbata **z cytryną**.* (с лимоном) |
| *Wracam **z pracy**.* | *Idę **z kolegą** do pracy.* |
| *Stół **z drewna**.* (из дерева) | *Stół **z krzesłami**.* (со стульями) |

### o: спрашивать vs рассказывать

| Падеж | Смысл | Пример |
|-------|-------|--------|
| Biernik | просить, спрашивать, спорить о чём | *Proszę **o rachunek**. Pytam **o drogę**.* |
| Miejscownik | говорить, думать, читать о чём | *Mówię **o pracy**. Myślę **o tobie**.* |

### po: за чем-то vs после чего-то

| Падеж | Смысл | Пример |
|-------|-------|--------|
| Biernik | за чем-то (сходить, принести) | *Idę **po chleb**.* — Иду за хлебом. |
| Miejscownik | после; по территории | *Wracam **po pracy**. Chodzę **po mieście**.* |

### w: день недели vs месяц/год

| Падеж | Когда | Пример |
|-------|-------|--------|
| Biernik | дни недели | *w poniedziałek, w środę, w sobotę* |
| Miejscownik | месяцы, годы, периоды | *w maju, w lipcu, w tym roku, w zeszłym tygodniu* |

### przez vs za — «час» в двух смыслах

| Конструкция | Значение | Пример |
|-------------|----------|--------|
| *przez* + B | в течение (сколько длилось) | *Uczyłem się **przez godzinę**.* |
| *za* + B | через (когда произойдёт) | *Wrócę **za godzinę**.* |
| *na* + B | на срок (планируемое пребывание) | *Jadę do Krakowa **na tydzień**.* |

## ze, we, ode — беглое -e

Когда после предлога идёт трудное для произношения скопление согласных, предлог получает *-e*.

| Базовая форма | С *-e* | Когда | Примеры |
|----------------|---------|-------|---------|
| *z* | *ze* | перед s, z, ś, ź, sz, ż, rz + согласная, а также перед другими труднопроизносимыми группами | *ze szkoły, ze stołu, ze Śląska, ze zmianami*; также *ze wsi, ze Lwowa* |
| *w* | *we* | перед w, f + согласная, а также перед другими труднопроизносимыми группами | *we Wrocławiu, we Francji, we Włoszech, we wtorek*; также *we krwi* |
| *od* | *ode* | почти только перед *mnie* | *ode mnie* |
| *bez* | *beze* | почти только перед *mnie* | *beze mnie* |
| *przez* | *przeze* | почти только перед *mnie* | *przeze mnie* |
| *nad / pod / przed* | *nade / pode / przede* | перед *mnie / mną* | *nade mną, pode mną, przede mną* |

### Предлоги + «я» (частотный набор)

| *do mnie* | *ode mnie* | *dla mnie* | *u mnie* | *o mnie* |
|-----------|------------|------------|----------|----------|
| *beze mnie* | *przeze mnie* | *we mnie* | *na mnie* | *za mnie* |
| *ze mną* | *nade mną* | *pode mną* | *przede mną* | *przy mnie* |

> Правило простое: если после предлога идёт две согласных подряд и язык спотыкается — скорее всего нужна форма с *-e*. Заучите частотные: *ze mną, we Wrocławiu, ode mnie, przede wszystkim*.

## Примеры в контексте

1. *Codziennie jadę **do pracy** autobusem, a **z pracy** wracam pieszo.* — Каждый день еду на работу автобусом, а с работы возвращаюсь пешком.
2. *Byłem **u lekarza**, teraz idę **do apteki**.* — Был у врача, теперь иду в аптеку.
3. ***Według mnie** ten film jest lepszy **od** poprzedniego.* — По-моему, этот фильм лучше предыдущего.
4. ***Dzięki tobie** zdałem egzamin **z polskiego**.* — Благодаря тебе я сдал экзамен по польскому.
5. *Położyłem klucze **na stole**, a portfel schowałem **do szuflady**.* — Положил ключи на стол, а кошелёк спрятал в ящик.
6. *W sobotę jedziemy **nad jezioro**, a w niedzielę wracamy **znad jeziora**.* — В субботу едем на озеро, в воскресенье возвращаемся с озера.
7. *Rozmawialiśmy **o pracy** **przez** dwie godziny.* — Разговаривали о работе два часа.
8. *Spotkajmy się **przed kinem**, **naprzeciwko poczty**.* — Встретимся перед кинотеатром, напротив почты.

## Częste błędy

### Общие ошибки

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| *Idę do koncert.* | *Idę na koncert.* | Мероприятия — *na* + B |
| *Jestem w poczcie.* | *Jestem na poczcie.* | Почта — из списка *na* |
| *Kładę książkę na stole.* | *Kładę książkę na stół.* | Есть движение → biernik |
| *Książka leży na stół.* | *Książka leży na stole.* | Нет движения → miejscownik |
| *Jadę nad morzem.* | *Jadę nad morze.* | Движение → biernik |
| *Mieszkam nad morze.* | *Mieszkam nad morzem.* | Покой → narzędnik |
| *Dzięki ciebie.* | *Dzięki tobie.* | *Dzięki* требует celownika |
| *Według mi.* | *Według mnie.* | *Według* требует dopełniacza |
| *w Wrocławiu* | *we Wrocławiu* | Перед *Wr-* нужна форма *we* |
| *z mną* | *ze mną* | Перед *mną* всегда *ze* |

### Ошибки от русского языка

| По-русски | ✗ Калька | ✅ По-польски | Комментарий |
|-----------|----------|---------------|-------------|
| иду **к** врачу | *idę ku lekarzowi* | *idę **do** lekarza* | К человеку — *do* + D. *Ku* так почти не употребляется |
| **у** меня есть книга | *u mnie jest książka* | ***Mam** książkę* | Польский *u* — только «в гостях, в кабинете»: *u lekarza, u babci* |
| сижу **за** столом | *siedzę za stołem* | *siedzę **przy** stole* | *Za stołem* = позади стола |
| иду **за** хлебом | *idę za chlebem* | *idę **po** chleb* | «Сходить за чем-то» — *po* + Biernik |
| **через** час вернусь | *przez godzinę wrócę* | ***za** godzinę wrócę* | *Przez godzinę* = «в течение часа» |
| говорить **по** телефону | *mówić po telefonie* | *mówić **przez** telefon* | *Przez* + Biernik |
| **в** университете | *w uniwersytecie* | ***na** uniwersytecie* | Вуз — из списка *na* |
| **в** деревне | *w wsi* | ***na** wsi* | Деревня — из списка *na* |
| **в** Венгрии | *w Węgrzech* | ***na** Węgrzech* | Венгрия, Литва, Словакия, Беларусь — *na* |
| **в/на** Украине | — | ***na** Ukrainie* (норма) | *W Ukrainie* тоже встречается, но традиционная форма надёжнее |
| зубная щётка **для** зубов | *szczoteczka dla zębów* | *szczoteczka **do** zębów* | Назначение предмета — *do* + D, не *dla* |
| спросить **о** дороге | *pytać o drodze* | *pytać **o drogę*** | *Pytać o* + Biernik, не Miejscownik |

> **Общая подсказка:** совпадение с русским — ловушка, а не помощь. Половина польских предлогов пишется как русские, но требует другого падежа. Проверяйте *do, po, za, przy, na* отдельно — именно они дают больше всего ошибок.
