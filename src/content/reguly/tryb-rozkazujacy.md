## Что это такое

*Tryb rozkazujący* — повелительное наклонение: приказ, просьба, совет, запрет, инструкция.

**Главное правило, которое надо запомнить сразу:** польский императив строится **от основы настоящего времени 3-го лица единственного числа**, а не от инфинитива.

| Инфинитив | 3 л. ед.ч. (наст. вр.) | → Императив *ty* |
|-----------|------------------------|------------------|
| *robić* | *robi* | *rób* |
| *pisać* | *pisze* | *pisz* |
| *czytać* | *czyta* | *czytaj* |
| *mówić* | *mówi* | *mów* |
| *pracować* | *pracuje* | *pracuj* |

> **Алгоритм:** поставь глагол в форму *on/ona* настоящего времени → отбрось конечную гласную *-e / -i / -y* → получишь императив. Если 3 л. оканчивается на *-a*, гласная остаётся и добавляется *-j*.

---

## Три модели образования

### 1. Голая основа — отбрасываем *-e / -i / -y*

Работает для глаголов на *-ę, -esz* и *-ę, -isz/-ysz*.

| 3 л. ед.ч. | Императив | Инфинитив |
|------------|-----------|-----------|
| *pisze* | *pisz* | *pisać* |
| *robi* | *rób* | *robić* |
| *mówi* | *mów* | *mówić* |
| *kupi* | *kup* | *kupić* |
| *uczy* | *ucz* | *uczyć* |
| *patrzy* | *patrz* | *patrzeć* |
| *idzie* | *idź* | *iść* |
| *bierze* | *bierz* | *brać* |
| *pracuje* | *pracuj* | *pracować* |
| *pije* | *pij* | *pić* |

> Глаголы на *-ować* всегда дают *-uj*: *pracuje → pracuj*, *kupuje → kupuj*, *dziękuje → dziękuj*, *próbuje → próbuj*. Это не отдельное правило — просто та же голая основа.

### 2. Модель на *-aj* — глаголы типа *czytam, czytasz*

Если 3 л. ед.ч. оканчивается на *-a*, просто добавляем *-j*.

| 3 л. ед.ч. | Императив | Инфинитив |
|------------|-----------|-----------|
| *czyta* | *czytaj* | *czytać* |
| *czeka* | *czekaj* | *czekać* |
| *pyta* | *pytaj* | *pytać* |
| *słucha* | *słuchaj* | *słuchać* |
| *pamięta* | *pamiętaj* | *pamiętać* |
| *uważa* | *uważaj* | *uważać* |
| *siada* | *siadaj* | *siadać* |

> **Исключение — глаголы на *-awać*:** императив образуется от инфинитива, а не от 3 л.: *dawać → dawaj* (не *«daj»* — это от *dać*), *wstawać → wstawaj*, *sprzedawać → sprzedawaj*.

### 3. Модель на *-ij / -yj* — когда основа «не выговаривается»

Если после отбрасывания гласной остаётся тяжёлое стечение согласных, добавляется *-ij* (после мягких и большинства согласных) или *-yj* (после отвердевших *cz, rz, sz, ż*).

| 3 л. ед.ч. | Императив | Инфинитив | Почему не голая основа |
|------------|-----------|-----------|------------------------|
| *śpi* | *śpij* | *spać* | осталось бы одно *śp-* |
| *zamknie* | *zamknij* | *zamknąć* | *-kn* на конце невозможно |
| *zacznie* | *zacznij* | *zacząć* | *-czn* |
| *odpocznie* | *odpocznij* | *odpocząć* | *-czn* |
| *biegnie* | *biegnij* | *biec* | *-gn* |
| *zapomni* | *zapomnij* | *zapomnieć* | *-mń* |
| *spóźni się* | *spóźnij się* | *spóźnić się* | *-źń* |
| *trze* | *trzyj* | *trzeć* | после *rz* → *-yj* |

> Точной механической проверки нет — ориентируйтесь на слух: если конец слова получается непроизносимым, нужен *-ij/-yj*. Спорные глаголы лучше просто запомнить.

## Все формы — одна таблица

Формы *my* и *wy* образуются от формы *ty* добавлением **-my** и **-cie**. Никаких изменений в основе.

| Лицо | Как образуется | *robić* | *pisać* | *czytać* | *być* |
|------|----------------|---------|---------|----------|-------|
| *ty* | база | *rób* | *pisz* | *czytaj* | *bądź* |
| *my* | + *-my* | *róbmy* | *piszmy* | *czytajmy* | *bądźmy* |
| *wy* | + *-cie* | *róbcie* | *piszcie* | *czytajcie* | *bądźcie* |
| *on / ona* | *niech* + 3 л. ед.ч. | *niech robi* | *niech pisze* | *niech czyta* | *niech będzie* |
| *oni / one* | *niech* + 3 л. мн.ч. | *niech robią* | *niech piszą* | *niech czytają* | *niech będą* |

> Обратите внимание: *ó* сохраняется во всех формах — *rób, róbmy, róbcie*; *mów, mówmy, mówcie*; *pomóż, pomóżmy, pomóżcie*.

## Третье лицо: только *niech*

**В польском нет синтетической формы 3-го лица императива.** Единственный способ — аналитическая конструкция **niech + настоящее время** (для *dk*-глаголов это формально будущее).

| Конструкция | Пример | Перевод |
|-------------|--------|---------|
| *niech* + 3 л. ед.ч. | *Niech robi, co chce.* | Пусть делает, что хочет. |
| *niech* + 3 л. мн.ч. | *Niech oni idą pierwsi.* | Пусть они идут первыми. |
| *niech* + *pan / pani* | *Niech pan wejdzie.* | Входите (вежливо, к мужчине). |
| *niech* + *państwo* | *Niech państwo usiądą.* | Присаживайтесь (к группе). |
| *niech* + 1 л. ед.ч. | *Niech pomyślę.* | Дай-ка подумаю. |

> **Русская подсказка:** *niech* = «пусть». Конструкция один в один: «пусть придёт» → *niech przyjdzie*. Здесь русская интуиция работает полностью.

## Вид и отрицание — самое важное различие

| | Утверждение (приказ) | Отрицание (запрет) |
|---|----------------------|--------------------|
| Вид | **dk** (совершенный) | **ndk** (несовершенный) |
| Логика | нужен результат | запрещается само действие |
| | *Zrób to!* | *Nie rób tego!* |
| | *Napisz!* | *Nie pisz!* |
| | *Zamknij okno!* | *Nie zamykaj okna!* |
| | *Kup to!* | *Nie kupuj tego!* |
| | *Weź to!* | *Nie bierz tego!* |
| | *Otwórz drzwi!* | *Nie otwieraj drzwi!* |
| | *Zadzwoń do niego!* | *Nie dzwoń do niego!* |
| | *Powiedz mu!* | *Nie mów mu!* |
| | *Usiądź!* | *Nie siadaj!* |
| | *Zjedz to!* | *Nie jedz tego!* |
| | *Zapłać!* | *Nie płać!* |

**Почему так.** Приказ нацелен на результат — поэтому *dk*. Запрет нацелен не на результат, а на **саму деятельность**: вы запрещаете не «дописать письмо», а «писать письмо» вообще. Отрицать завершённость бессмысленно — отрицают процесс.

> **Заодно про падеж:** прямое дополнение под отрицанием переходит из biernika в **dopełniacz**: *Zamknij **okno*** → *Nie zamykaj **okna***; *Kup **to*** → *Nie kupuj **tego***. Две ошибки в одном месте — следите за обеими.

### Исключение: *dk* под отрицанием = предостережение

Совершенный вид с *nie* звучит не как запрет, а как «смотри не...».

| Форма | Перевод |
|-------|---------|
| *Nie zapomnij!* | Не забудь! |
| *Nie spóźnij się!* | Не опоздай! |
| *Nie zgub kluczy!* | Не потеряй ключи! |
| *Nie obudź dziecka!* | Не разбуди ребёнка! |
| *Nie przewróć się!* | Не упади! |

> Русская интуиция здесь совпадает: «не делай» (нсв, запрет) vs «не забудь» (св, предостережение). Ровно та же пара.

## Неправильные и трудные формы

| Инфинитив | *ty* | *my* | *wy* | Комментарий |
|-----------|------|------|------|-------------|
| *być* | *bądź* | *bądźmy* | *bądźcie* | супплетивная основа |
| *mieć* | *miej* | *miejmy* | *miejcie* | не *«maj»* |
| *jeść* | *jedz* | *jedzmy* | *jedzcie* | основа из 3 л. мн.ч. *jedzą* |
| *wziąć* | *weź* | *weźmy* | *weźcie* | от *weźmie*, но без *-m* |
| *iść* | *idź* | *idźmy* | *idźcie* | от *idzie* |
| *jechać* | *jedź* | *jedźmy* | *jedźcie* | от *jedzie* |
| *dać* | *daj* | *dajmy* | *dajcie* | от *da* |
| *powiedzieć* | *powiedz* | *powiedzmy* | *powiedzcie* | основа из *powiedzą* |
| *wiedzieć* | *wiedz* | *wiedzmy* | *wiedzcie* | то же |
| *pomóc* | *pomóż* | *pomóżmy* | *pomóżcie* | от *pomoże*, *o → ó* |
| *stać* | *stój* | *stójmy* | *stójcie* | от *stoi* |
| *bać się* | *bój się* | *bójmy się* | *bójcie się* | от *boi się* |
| *wstać* | *wstań* | *wstańmy* | *wstańcie* | от *wstanie* |
| *zdjąć* | *zdejmij* | *zdejmijmy* | *zdejmijcie* | основа *zdejm-* |

> **Две пары, которые русскоговорящие путают постоянно:**
> *jedz* (ешь!) ≠ *jedź* (езжай!) — разница только в диакритике.
> *bądź* (будь!) ≠ *budź* (буди!, от *budzić*).

## Чередования в основе императива

### Согласные

| Чередование | Примеры |
|-------------|---------|
| *ci → ć* | *płaci → płać*, *wróci → wróć*, *zapłaci → zapłać*, *leci → leć* |
| *dzi → dź* | *chodzi → chodź*, *jedzie → jedź*, *usiądzie → usiądź*, *sprawdzi → sprawdź* |
| *si → ś* | *prosi → proś*, *nosi → noś*, *niesie → nieś* |
| *zi → ź* | *wozi → woź*, *zawiezie → zawieź* |
| *ni → ń* | *dzwoni → dzwoń*, *wstanie → wstań*, *zostanie → zostań*, *przestanie → przestań* |
| *li → l* | *myśli → myśl*, *pozwoli → pozwól* |
| *rz* | *otworzy → otwórz*, *powtórzy → powtórz*, *patrzy → patrz* |
| *ż* | *pomoże → pomóż*, *pokaże → pokaż* |
| *sz / cz* | *napisze → napisz*, *skończy → skończ*, *wytłumaczy → wytłumacz* |

**Отдельно — мягкие губные твердеют.** В настоящем времени *p, b, w, m* мягкие, в императиве становятся твёрдыми:

*kupi → kup*, *robi → rób*, *mówi → mów*, *karmi → karm*, *martwi się → martw się*, *zostawi → zostaw*.

### Гласные: *o → ó* в закрытом слоге

| Пример | |
|--------|---|
| *robi → rób* | *zrobi → zrób* |
| *pomoże → pomóż* | *otworzy → otwórz* |
| *stoi → stój* | *boi się → bój się* |
| *pozwoli → pozwól* | *spojrzy → spójrz* |

> *ó* не исчезает в формах *my/wy*: *róbmy, otwórzcie, pomóżmy, stójcie*.

## Вежливость и регистр — практически самое важное

**Голый императив, обращённый к незнакомому человеку, звучит по-польски резко** — примерно как русское «Подожди!» вместо «Подождите, пожалуйста». В Польше это заметная социальная ошибка, и на устной части B1 контроль регистра оценивается.

Форма на *ty* уместна только с теми, с кем вы **на *ty***: друзья, семья, коллеги-ровесники, дети.

| Ситуация | Инструмент | Пример |
|----------|-----------|--------|
| Свои, на *ty* | императив *ty* | *Zamknij okno.* |
| Свои, мягче | императив + *proszę* | *Zamknij, proszę, okno.* |
| Свои, ещё мягче | *czy mógłbyś / mogłabyś* + inf. | *Czy mógłbyś zamknąć okno?* |
| Незнакомый, нейтрально-формально | ***proszę* + инфинитив** | *Proszę zamknąć okno.* |
| Незнакомый, подчёркнуто вежливо | ***niech pan / pani* + 3 л.** | *Niech pan zamknie okno.* |
| Объявления, инструкции | *proszę* + inf. / безличное | *Proszę nie palić.* / *Nie wolno palić.* |

### *Proszę* + инфинитив — рабочая лошадь формального польского

| Пример | Перевод |
|--------|---------|
| *Proszę usiąść.* | Присаживайтесь. |
| *Proszę wejść.* | Входите. |
| *Proszę czekać.* | Ждите. |
| *Proszę wypełnić formularz.* | Заполните бланк. |
| *Proszę mówić wolniej.* | Говорите медленнее. |
| *Proszę się nie martwić.* | Не волнуйтесь. |
| *Proszę nie przeszkadzać.* | Не мешайте. |

> Конструкция не меняется ни по лицу, ни по числу — одинаково к мужчине, женщине и группе. Для B1 это самый надёжный способ вообще не ошибиться в регистре.

### *Niech pan / pani* + 3 лицо

| Пример | Перевод |
|--------|---------|
| *Niech pani poczeka chwilę.* | Подождите минутку. |
| *Niech pan wejdzie.* | Входите. |
| *Niech pan się nie denerwuje.* | Не нервничайте. |
| *Niech państwo usiądą.* | Присаживайтесь (группе). |

> **Разница оттенка:** *proszę* + инфинитив — нейтрально-официально (окно, кабинет, объявление). *Niech pan/pani* — теплее и личнее, но при резкой интонации может прозвучать как нажим. На экзамене безопаснее *proszę* + инфинитив.

> **Бонус, который постоянно нужен в кафе и магазине:** заказ делают не императивом, а формой *poproszę* — *Poproszę kawę i wodę.* Дословно «попрошу», по функции — «мне, пожалуйста».

## Примеры в контексте

1. *Zrób to dzisiaj, jutro nie będzie czasu.* — Сделай это сегодня, завтра не будет времени.
2. *Nie zamykaj okna, jest duszno.* — Не закрывай окно, душно.
3. *Chodźmy na spacer, pogoda jest świetna.* — Пойдём гулять, погода отличная.
4. *Dzieci, umyjcie ręce przed obiadem!* — Дети, помойте руки перед обедом!
5. *Proszę usiąść i wypełnić ten formularz.* — Присаживайтесь и заполните этот бланк.
6. *Niech pani poczeka, zaraz sprawdzę.* — Подождите, я сейчас проверю.
7. *Bądź cierpliwy, to potrwa chwilę.* — Будь терпелив, это займёт минуту.
8. *Nie zapomnij o spotkaniu w środę.* — Не забудь о встрече в среду.
9. *Weź parasol, bo będzie padać.* — Возьми зонт, будет дождь.
10. *Niech oni sami zdecydują.* — Пусть они сами решат.

## Частые ошибки

| Ошибка | Правильно | Почему |
|--------|-----------|--------|
| *robij / robaj* | *rób* | Императив строится от *robi* (3 л.), а не от инфинитива *robić* |
| *pracowaj* | *pracuj* | От *pracuje*, а не от *pracować*; все глаголы на *-ować* → *-uj* |
| *piszaj* | *pisz* | *-aj* только там, где 3 л. оканчивается на *-a* (*czyta → czytaj*) |
| *maj* | *miej* | *mieć* — неправильный глагол |
| *budź dobry* | *bądź dobry* | *bądź* — от *być*; *budź* — от *budzić* (буди) |
| *Jedź zupę.* | *Jedz zupę.* | *jedz* — ешь, *jedź* — езжай |
| *weźmi* | *weź* | Русское «возьми» тянет за собой лишний слог |
| *pomoż* | *pomóż* | Обязательное *o → ó* |
| *Nie zrób tego!* | *Nie rób tego!* | Запрет — несовершенный вид |
| *Nie zamykaj okno.* | *Nie zamykaj okna.* | Под отрицанием — dopełniacz |
| *Zamykaj drzwi!* (разовая просьба) | *Zamknij drzwi!* | Приказ на результат — совершенный вид |
| *Poczekaj!* (незнакомому) | *Proszę poczekać.* / *Niech pan poczeka.* | Голый императив к чужому звучит грубо |
| *Proszę usiądź.* | *Proszę usiąść.* | После *proszę* — инфинитив, а не императив |
| *Niech pan wejść.* | *Niech pan wejdzie.* | После *niech* — 3 л. настоящего/будущего, а не инфинитив |
| *Niech pan czekać.* | *Niech pan czeka.* | То же самое |

> **Главная ловушка для русскоговорящих.** В русском императив образуется от основы настоящего времени, но привычка всё равно опирается на инфинитив: «делать → делай», «работать → работай». По-польски отправная точка — **строго форма *on/ona* настоящего времени**: *robi → rób* (а не *«robij»*), *pracuje → pracuj* (а не *«pracowaj»*), *pisze → pisz*. Прежде чем сказать императив, мысленно проговорите форму 3-го лица.

> **А вот с видом русская интуиция помогает, а не мешает.** «Сделай!» / «Не делай!» = *Zrób!* / *Nie rób!* — правило то же, и работает оно в обоих языках одинаково. *«Nie zrób tego»* не грубо, а просто странно: совершенный вид под отрицанием читается как предостережение («смотри не...»), а здесь предостерегать не от чего. Ровно как русское «не разбей» — это не запрет, а предупреждение. Подробнее: [⏳ Aspekt →](/polish-hub/reguly/aspekt/)
