# Plan — Сайт 2.0: «сайт, который помнит»

> Утверждённый дизайн от 2026-08-11. Запрос Жени: прогресс должен накапливаться (логин, лучшие результаты), больше квизов по темам, ежедневные индивидуальные уроки, озвучка, чтение, подготовка к экзамену B1. Копия спека лежит в репо: `docs/superpowers/specs/2026-08-11-hub2-design.md`.

## Ключевые решения

| Вопрос | Решение |
|--------|---------|
| Вход | Аватар (Żenia/Oleg/Lena) + PIN 4 цифры. Под капотом Firebase Auth email+password: служебный email, пароль детерминированно из PIN → Security Rules реально защищают запись |
| Бэкенд | Firebase Firestore (Spark, бесплатно). План Б — Cloudflare Workers+D1, если Firebase урежет free tier |
| «Следующий курс» | Два направления: глубина (серии квизов на тему) + экзаменационный трек B1. Курс B1→B2 — после закрытия B1 |
| Урок дня | 15–20 минут: повторка Лейтнера (5 мин) + навык дня (10–15 мин), ротация Czytanie→Pisanie→Słuchanie→Gramatyka |
| Чтение | Смешанно: новые тексты сразу по-польски (B1) на темы «Другого взгляда на мир», **без переноса нод из волта** — приватность не затронута |
| Словарь | Glosbe без API (его нет бесплатного): клик по слову → всплывашка: 🔊 TTS · ссылка Glosbe · сохранить в Słówka |

## 1. Аккаунты и прогресс

- Экран входа: три аватара + PIN. Сессия запоминается на устройстве.
- Firestore на каждого: `attempts` (все попытки), `best` (лучший результат по квизу), `leitner` (состояние словаря — мигрирует из localStorage, синхронно между устройствами), `topics` (самооценка «понимаю/шатко/не понимаю» + авто-обновление по квизам), `streak`.
- Дашборд после входа: стрик, слова к повторке, слабые темы, последние результаты + общий блок «кто что прошёл» на троих.

## 2. Ścieżki — треки по темам

- Трек = правило + серия квизов: **Rozgrzewka** (10 лёгких) → **Trening** (20 средних) → **Mistrz** (смешанные механики). Трек закрыт при Mistrz ≥ 90%.
- Перекрёстные ссылки: правило ↔ квизы ↔ смежные правила («потренируй это» прямо в тексте).
- Старт ~10 треков: 8 падежно-грамматических + aspekt + czasy.

## 3. Новые механики квизов

К существующим (mc, tf, typein, tap-to-place, match) добавить:
- **Соединялки** (расширенный match): слово↔перевод, глагол↔падеж
- **Ułóż zdanie** — собери предложение из плиток
- **Dyktando** — TTS-слово/фраза → впиши (это аудирование)
- **Cloze-текст** — абзац с пропусками (экзаменационный формат)
- **Odd one out** — найди лишнее

## 4. «Dzisiaj» — урок дня

- Генерируется из прогресса: повторка Лейтнера + блок навыка дня по ротации.
- Pisanie на статике ограничено (эссе не проверить): перевод предложений с подсказками, cloze, «напиши 5 предложений» с самопроверкой по образцу.
- Урок дня засчитывает стрик; заморозка стрика — решить при реализации.

## 5. Озвучка и словарь

- Web Speech API (pl-PL) везде: фишки слов, предложения квизов, тексты чтения. Качество зависит от устройства; отсутствие польского голоса показывать явно.
- Клик-словарь в текстах чтения; сохранённые слова падают в личную колоду Лейтнера.

## 6. Czytanie

- Новые польские тексты B1 на темы серии (блок-вселенная, энтропия, мозг, память…), ~200–300 слов + глоссарий + 5–7 вопросов + клик-словарь. Старт: 10 текстов.

## 7. Egzamin B1

- Пробные тесты в формате certyfikat B1: czytanie / słuchanie / gramatyka с таймингами, pisanie с образцами. Динамика готовности по частям — в профиле.

## 8. Этапы (≈ вечер каждый)

| # | Этап | Результат |
|---|------|-----------|
| 1 | Firebase: аватар+PIN, запись результатов, лучшие результаты, дашборд | Прогресс перестаёт теряться |
| 2 | Лейтнер в облако + стрик + «кто что прошёл» | Слова синхронны между устройствами |
| 3 | TTS + клик-словарь + Dyktando | Озвучка и аудирование |
| 4 | Ścieżki: структура + первые 3 темы | Много квизов на тему |
| 5 | «Dzisiaj» — генератор урока дня | Ежедневный ритм |
| 6 | Уроки 14–17 + Wielki Mix #2 | Курс B1 дописан |
| 7 | Czytanie: первые 10 текстов | Чтение |
| 8 | Egzamin: первый пробный тест | Экзаменационный трек |
| … | Новые треки, тексты, механики | Полгода сайд-работы |

Этапы 3–7 переставляемы; 1–2 — строго первыми.

## Осознанные ограничения

- Аудитория — трое; вырезаны: лидерборды, пуш-уведомления, мобильное приложение, серверная проверка эссе.
- PIN — реальная защита записи через Firebase Auth, но сайт остаётся публичным (noindex): чтение контента доступно всем, кто знает ссылку.
- Free tier Firebase дрейфует — проверять условия раз в полгода (риск из [[Research — Архитектура сайта]]).
