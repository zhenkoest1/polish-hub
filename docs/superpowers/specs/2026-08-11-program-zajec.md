# Plan — Program zajęć: интерактив, сессии-соло, путь к экзамену

> Продолжение [[Plan — Сайт 2.0]]. Запрос Жени от 2026-08-11 (вечер): задания в лекциях должны стать интерактивными («куда писать? надо, чтобы я написал, ты запомнил, и потом можно проверить»), нужны индивидуальные занятия на 40 минут (чтение + аудирование + правила), и программа «от уровня к уровню» на несколько месяцев до экзамена B1. Копия в репо: `docs/superpowers/specs/2026-08-11-program-zajec.md`.

## Проблема, которую решаем

Сейчас лекции — это текст с заданиями «на поговорить»: *Mini-pisanie*, *Runda 1 — proces czy wynik* и т.п. Писать **некуда**: нет поля ввода, нет проверки, нет сохранения. Половина ценности заданий теряется, если делаешь их один.

## 1. Silnik ćwiczeń — интерактив внутри лекций

Новый маленький движок (по образцу quiz-engine, но встраиваемый в текст лекции). Типы упражнений:

| Тип | Как выглядит | Пример из лекций |
|-----|--------------|------------------|
| **wybór w zdaniu** | В предложении две кнопки — щёлкаешь одну, сразу видно ✓/✗ | «Wczoraj cały wieczór *(czytać / przeczytać)* tę książkę» |
| **wpisz** | Поле ввода прямо в строке, кнопка Sprawdź в конце раунда | «naukowiec → ____» |
| **połącz** | Соединялки: клик слева → клик справа (как match в квизах) | глагол ↔ падеж |
| **mini-pisanie** | Текстовое поле на 3–5 предложений → **сохраняется в твой Zeszyt** (Firestore), на встрече читаешь вслух | «Wypiszcie trzy sprawy, których nie skończyliście…» |
| **na głos** | Устное задание + чекбокс «zrobione» — считается в прогресс | «przeczytaj i przetłumacz» |

Правила движка:

- Каждый **раунд заканчивается кнопкой Sprawdź** — проверка всего блока разом, ✓/✗ по каждому пункту, правильные ответы показываются после проверки
- Ответы «wpisz» проверяются как в квизах: stripDiacritics ловит «почти правильно» (забыл ą/ę)
- Всё написанное сохраняется в Firestore: подколлекция `zeszyt` у юзера (лекция, задание, текст, дата). В профиле появляется раздел **«Mój zeszyt»** — все твои письменные работы в одном месте
- Результаты ćwiczeń считаются в прогресс лекции (видно в профиле: лекция «пройдена интерактивно»)

**Порядок переделки лекций:** начать с 10-й (свежие, там больше всего интерактивных заданий), потом 11–13, потом 1–9 по мере сил.

## 2. Sesja solo — занятие одного на 40 минут

Страница «Sesja» собирает занятие автоматически. Структура (≈40 мин):

| Мин | Блок | Что происходит |
|-----|------|----------------|
| 5 | **Rozgrzewka** | Повторка слов Лейтнера (что назрело сегодня) |
| 12 | **Czytanie** | Большой текст уровня N + 6–8 вопросов на понимание (mc/tf) |
| 10 | **Słuchanie** | Текст озвучен TTS (pl-PL), слушаешь БЕЗ текста → вопросы + короткое dyktando |
| 8 | **Gramatyka** | Правило дня + серия ćwiczeń по нему |
| 5 | **Mini-pisanie** | 3–5 предложений в Zeszyt по теме текста |

- Сессия записывается в Firestore → стрик, история сессий в профиле
- Таймер по блокам — мягкий (подсказывает, не обрывает)
- Уровни текстов растут: **poziom 1** (150 слов, простые времена) → **poziom 5** (350+ слов, экзаменационная сложность). Переход — когда понимание стабильно ≥80%

## 3. Программа до экзамена (месяцы)

Сертификатный B1 = 4 части: rozumienie ze słuchu · rozumienie tekstów · poprawność gramatyczna · pisanie (+ mówienie устно). Программа строится вокруг них:

| Месяц | Фокус | Что на сайте |
|-------|-------|--------------|
| **Sierpień** | Аспект + времена (закрепление уроков 10–13), ритм сессий 3×/неделю | Silnik ćwiczeń, retrofit лекций 10–13, первые Sesje solo, тексты poziom 1–2 |
| **Wrzesień** | Падежи вглубь (8 тем → серии квизов Rozgrzewka→Trening→Mistrz), уроки 14–15 | Ścieżki (этап 4 из [[Plan — Сайт 2.0]]), тексты poziom 2–3, dyktanda |
| **Październik** | Формат экзамена: тайминги, типовые задания всех 4 частей, уроки 16–17 | Раздел Egzamin: пробники частями, тексты poziom 3–4, pisanie по образцам |
| **Listopad** | Полные пробные экзамены + работа над ошибками | 2–3 полных пробника с таймером, повторка слабых тем из статистики |

Слабые темы определяются автоматически: по результатам квизов и ćwiczeń (то, что в Сайт 2.0 названо `topics`).

## 4. Этапы работ (каждый ≈ вечер)

| # | Этап | Результат |
|---|------|-----------|
| A | Silnik ćwiczeń: wybór w zdaniu + wpisz + Sprawdź; retrofit лекции 10 | Задания стали интерактивными |
| B | Zeszyt (mini-pisanie → Firestore) + «Mój zeszyt» в профиле; retrofit 11–13 | Письмо сохраняется и проверяется на встрече |
| C | Połącz (стрелочки) + na głos с чекбоксами; retrofit лекций 1–9 (частями) | Весь курс интерактивен |
| D | Sesja solo: страница, генератор 40′, запись сессий, стрик | Ежедневное занятие одного |
| E | Czytanie: первые 10 текстов poziom 1–2 с вопросами | Материал для сессий |
| F | Słuchanie: TTS-проигрывание текстов + dyktando | Аудирование |
| G | Ścieżki: 3 первых темы с сериями квизов | Глубина по темам |
| H | Egzamin: пробник części czytanie + gramatyka с таймером | Экзаменационный трек |
| I | Тексты poziom 3–4, пробники #2–3, mówienie-чеклисты | Октябрь-ноябрь |

Порядок A→B→D — жёсткий (интерактив прежде всего, это сегодняшняя боль). Остальное переставляемо.

## Технические заметки

- Silnik ćwiczeń живёт в лекциях: разметка упражнений — в markdown лекции спец-блоком (` ```cwiczenie ``` ` с JSON), рендер — клиентский скрипт. Валидатор `tresc.test.mjs` расширяется на проверку этих блоков
- Zeszyt: `users/{uid}/zeszyt/{autoId}` — {lekcja, zadanie, tekst, ts}. Rules: писать/читать только своё (никто чужих сочинений не видит, если не решим иначе)
- TTS: Web Speech API, голос pl-PL; где голоса нет — честное сообщение (решение из [[Plan — Сайт 2.0]])
- Тексты чтения: temat из «Другого взгляда» (космос, мозг, память…) — новые, по-польски, без переноса нод из волта (решение приватности из [[Plan — Сайт 2.0]])
